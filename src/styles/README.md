# Styles

This directory contains all global and modular style files for the project.

- `globals.scss`: Global styles and base CSS rules applied throughout the application.
- `tailwind.scss`: Tailwind CSS configuration and imports.
- `components/`: SCSS modules for styling individual React components.
- `pages/`: SCSS modules for styling specific pages or page sections.
- `variable/`: SCSS variables such as colors, fonts, and spacing used across the project.

Organize and update styles here to ensure consistency and maintainability in the application's appearance.

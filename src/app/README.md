# App

This directory contains the main application structure and routing configuration.

- `layout.jsx`: The root layout component that wraps all pages and provides global structure (e.g., navigation, footer).
- `page.jsx`: The main entry point for the root page.
- `about/`, `blog/`, `internship/`, `news/`, `people/`, `project/`: Subdirectories for each main route, containing their respective pages and layouts.

Organize top-level pages and layouts here to define the application's navigation and overall structure.

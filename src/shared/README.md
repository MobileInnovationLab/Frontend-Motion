# Shared

This directory contains shared modules and utilities that are reused across multiple features of the application.

- `api/`: Centralized API utilities and configuration for making HTTP requests.
- `components/`: Reusable UI components that are not specific to any single feature.
- `hooks/`: Custom React hooks that provide shared logic and can be used throughout the app.
- `utils/`: Utility functions and helpers for common operations.

Organize shared resources here to promote code reuse and maintainability across the project.

# Features

This directory contains the main feature modules of the application.  
Each subfolder represents a distinct feature or section, encapsulating its own components, hooks, services, constants, and views.

- `home/`: Home page feature and its related logic and UI.
- `internship/`: Internship-related pages, components, and logic.
- `news/`: News section, including news listing and detail pages.
- `people/`: People or team member-related features.
- `project/`: Project showcase and related functionality.

Organize each feature in its own folder to promote modularity, scalability, and maintainability.
